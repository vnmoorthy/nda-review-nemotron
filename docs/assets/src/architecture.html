SOURCE

ContractNLI dataset

  • 607 real NDAs (EDGAR + web), CC-BY-4.0
  • 17 expert-annotated hypotheses each
  • label + supporting span ids
  • doc-level split: 423 / 61 / 123
contractnli.py

Prompt builder (single source of truth)

  • doc_spans() → contract as numbered clauses [0]…[n]
  • build_messages() → system (instruction + 17-item checklist) + user (contract)
  • completion = strict JSON: label + evidence per item
  • enable_thinking=False via chat-template kwargs

SAGEMAKER TRAINING JOB · ModelTrainer

LoRA SFT of Nemotron 3.5 Bolt E4B

  • PyTorch 2.8 DLC · scripts/train.py (TRL SFTTrainer + PEFT)
  • LoRA r=32 α=64 on q/k/v/o + MLP · bf16 · 1 epoch · lr 1e-4 cosine
  • completion-only loss: only the JSON answer is supervised
  • instance preference: g7.2xl → g6e.2xl → g5.2xl → …
  • ~32 min on 1× ml.g7.2xlarge
